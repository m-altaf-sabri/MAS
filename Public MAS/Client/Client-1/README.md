# Mohd Altaf Portfolio

A responsive, single-page portfolio website created from the supplied resume.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and subtle scroll reveal

## Run locally

Open `index.html` directly in a browser, or serve the folder with any simple static web server.

## Publish

The project is static HTML/CSS/JS, so it can be deployed to GitHub Pages, Netlify, Vercel, or another static hosting service.

## Content note

The project is static HTML/CSS/JS, so it can be deployed to GitHub Pages, Netlify, Vercel, or another static hosting service.
